# 📋 Planificador de Tareas Web

Aplicación web para la gestión de tareas diarias, diseñada con una interfaz moderna, intuitiva y enfocada en la productividad.

El proyecto busca facilitar la organización de actividades mediante la creación, visualización, edición, filtrado y gestión completa de tareas.

---

## Estado del proyecto

🟢 **Proyecto finalizado e interactivo**

El proyecto se encuentra completamente desarrollado y funcional. Cuenta con una interfaz responsive, navegación entre diferentes módulos, gestión dinámica de tareas e integración con el backend mediante una API REST.

## 🔌 Backend

El frontend se encuentra integrado con el backend desarrollado en **Spring Boot**, encargado de gestionar la lógica de negocio, las operaciones CRUD y la persistencia de las tareas.

### Tecnologías del backend

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Supabase
* Swagger / OpenAPI
* Render
